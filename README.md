# usfkhoury.com

Personal landing page at **[usfkhoury.com](https://usfkhoury.com)**.

## What's here

- **`index.html`** — the entire website (HTML, CSS, and JavaScript, all in one file).
- **`assets/`** — two short video clips used by a hidden feature on the page.

That's it. No build step, nothing to install.

## To edit the site

Open `index.html` in any text editor, change what you want, and save.

## To publish changes

Push to GitHub. Netlify picks up the change automatically and the live site updates in about a minute.
